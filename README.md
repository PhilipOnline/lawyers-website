# Irakli Tedoradze — Legal & Strategic Advisory

Статичный адаптивный сайт на HTML, CSS и JavaScript. Без базы данных, сборки, форм и внешних сервисов. Три языка: грузинский (по умолчанию), английский и русский. Выбор языка сохраняется в браузере. Прямые ссылки: `?lang=ka`, `?lang=en`, `?lang=ru`.

## Локальный просмотр

В каталоге проекта выполните:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080.

## Публикация на GitHub Pages

1. Загрузите изменения в ветку `main` или `master` репозитория GitHub.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Запустите workflow **Deploy static site to GitHub Pages** на вкладке Actions, если он ещё не запустился автоматически.

Workflow публикует только `index.html` и каталог `assets`. Относительные пути поддерживают размещение в подкаталоге репозитория.

## Контент

- Тексты всех языков находятся в `translations` в `assets/app.js`.
- Телефон, email и LinkedIn заданы в объекте `CONTACT` в начале `assets/app.js`. Ссылка WhatsApp строится из телефона; Viber и Telegram указаны как доступные по тому же номеру.
- Имя в шапке и подвале задаётся в `index.html`, заголовок страницы — в `assets/app.js`.
- Цвета, отступы и адаптивные стили — `assets/style.css`.

Портрет и интерьер временно отображаются как фрагменты предоставленного референса через CSS-фон (`assets/reference.jpg`). Для качественного изображения на больших экранах замените их оригинальными фотографиями и обновите `.hero-photo` и `.office-photo` в CSS. Утверждения о стаже и квалификации из референса не добавлены без подтверждения. Содержание обновлено по `data/Irakli_Tedoradze_Legal_Profile_Trilingual_Full.pdf`: профиль, пять направлений с раскрывающимися подробностями, преимущества и контакты на трёх языках. Заголовки и краткие описания адаптированы для сайта; подробности услуг перенесены из соответствующих языковых версий PDF. Сам PDF не публикуется.
